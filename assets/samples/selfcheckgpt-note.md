# SelfCheckGPT: Zero-Resource Black-Box Hallucination Detection for Generative Large Language Models

## 1 一、要解决的问题

### 1.1 生成式大语言模型的事实幻觉问题

生成式大语言模型（LLM），如 GPT-3、PaLM、ChatGPT，能够针对各种用户提示生成高度流畅、逼真的文本，并已被广泛应用于报告草拟、虚拟助手、摘要系统等场景。然而，LLM 在生成文本时会“幻觉”事实：模型可以非常自信地编造虚构信息，做出非事实性陈述，这会严重削弱用户对模型输出的信任。

幻觉问题在文本生成任务中广泛存在，包括摘要生成、对话生成等。更值得关注的是，目前几乎没有合适的方法来可靠地识别 LLM 的幻觉。因此，本文的核心问题是：**如何自动检测生成式 LLM 输出中的幻觉内容**。

### 1.2 黑盒与零资源约束

现有的事实检查方法存在两个主要局限：

- **需要获取输出概率分布**。基于不确定性的方法通常依赖 token 级概率或熵等内在不确定性指标。但当模型通过受限的外部 API 访问时（如 ChatGPT），用户通常无法获得 token 级概率分布。
- **需要外部数据库**。基于事实核查的方法通常需要检索外部证据库，并与单独的复杂模块交互。事实只能相对于数据库中已有的知识来评估，且幻觉并不限于纯事实核查任务，还广泛出现在摘要、对话等场景。

因此，本文试图解决一个更具挑战性的问题：**在零资源（不使用外部数据库）、黑盒（仅能获得文本输出）条件下，检测 LLM 生成文本中的幻觉**。

### 1.3 任务定义

本文将幻觉检测定义为两个层次的评估任务：

- **句子级幻觉检测**：给定 LLM 响应中的每个句子，预测其是否是非事实性的。具体包括两个子任务：检测所有非事实句（NonFact，将 major inaccurate 与 minor inaccurate 合并）和检测严重不准确句（NonFact\*，只检测 major inaccurate，且排除完全幻觉的段落）。
- **段落级事实性排序**：给定整段响应，预测一个连续分数，用于对段落的事实性进行排序，分数需与人类判断高度相关。

### 1.4 数据集与人工标注方案

由于当时没有标准的 LLM 幻觉检测数据集，本文构建了一个新数据集。从 WikiBio 测试集中按段落长度排名，随机抽取前 20% 最长文章中的 238 个概念，用 GPT-3（text-davinci-003）以提示 `"This is a Wikipedia passage about {concept}:"` 生成维基百科风格段落。数据集统计如下：

| 统计项 | 数值 |
|---|---|
| 段落数 | 238 |
| 句子数 | 1908 |
| 每段 token 数 | 184.7 ± 36.9 |

每个句子被人工标注为三类之一：

- **Major Inaccurate（严重不准确，Non-Factual=1）**：句子完全幻觉，与主题无关。
- **Minor Inaccurate（轻微不准确，Non-Factual=0.5）**：句子包含部分非事实信息，但总体上与主题相关。
- **Accurate（准确，Factual=0）**：句子信息准确。

在 1908 个句子中，761 句（39.9%）被标注为 major inaccurate，631 句（33.1%）为 minor inaccurate，516 句（27.0%）为 accurate。其中 201 句由两名标注者共同标注，Cohen’s κ 在三分类下为 0.595，在二分类下为 0.748，分别表示中等和实质性一致。段落级分数由句子级标签平均得到，其分布显示在 +1.0 处存在一个高峰，称为“完全幻觉”段落，即整段响应完全由 LLM 虚构。

## 2 二、前人方案及其不足

### 2.1 基于输出概率与熵的灰盒不确定性评估

该方法利用 LLM 输出层的 token 级概率分布作为不确定性信号。设响应 R 的第 i 个句子共有 J 个 token，第 j 个 token 的生成概率为 p_{ij}。定义两种概率指标：

$$
\text{Avg}(-\log p) = -\frac{1}{J}\sum_{j}\log p_{ij}
$$

$$
\text{Max}(-\log p) = \max_{j}(-\log p_{ij})
$$

此外，定义第 j 个 token 输出分布的熵为：

$$
H_{ij} = -\sum_{\tilde w\in W} p_{ij}(\tilde w)\log p_{ij}(\tilde w)
$$

由此得到两种熵指标：

$$
\text{Avg}(H) = \frac{1}{J}\sum_{j}H_{ij}; \quad \text{Max}(H)=\max_{j}H_{ij}
$$

**直觉**：事实性句子中的 token 通常具有更高的似然和更低的熵；而幻觉更可能来自概率分布平坦、不确定性高的位置。实验表明，GPT-3 自身概率指标确实是强基线，例如 Avg(-log p) 在 NonFact 任务上 AUC-PR 为 83.21，Fact 任务为 53.97；Max(-log p) 在 NonFact 上达到 87.51。但**不足**是：这些方法需要完整的输出概率分布，而黑盒 API（如 ChatGPT）往往不提供这些信息。

### 2.2 基于外部数据库的事实核查

事实核查方法通常包含多个阶段：声明检测、证据检索和裁决预测。代表性工作包括基于 FEVER 数据集的自动事实核查。**不足**是：需要访问外部数据库，事实只能相对于数据库中的知识来评估；数据库未必覆盖所有概念；推理成本高；并且幻觉现象不只发生在纯事实核查场景，因此难以作为通用 LLM 幻觉检测方案。

### 2.3 白盒内部状态分类器

Azaria 和 Mitchell（2023）提出训练一个多层感知机分类器，以 LLM 的隐藏表示作为输入，预测句子的真伪。**不足**是：这是白盒方法，需要访问 LLM 内部状态，而很多 API 调用无法提供这些信息；同时需要标注数据进行监督训练，泛化性受限。

### 2.4 LLM 自评估 prompting

Kadavath 等（2022）提出自评估方法：提示 LLM 对自身先前的预测进行评估，例如预测其生成的答案/响应为真的概率。**不足**是：该方法依赖 LLM 的自我评估能力，对于复杂事实性判断可能不够可靠；且不是结构化的事实核查方案。

### 2.5 代理 LLM（Proxy LLM）近似的黑盒方法

为了在没有 token 概率的情况下近似灰盒方法，可以使用一个完全可访问的“代理 LLM”（如 LLaMA），为黑盒 LLM 生成的文本计算 token 级概率。**不足**是：实验结果（表 2）表明，代理 LLM 的性能明显差于生成文本的原始 LLM。例如 LLaMA-30B 的 Avg(-log p) 在 NonFact 任务上 AUC-PR 仅为 75.43，Fact 为 41.29；Avg(H) 在 NonFact 上为 80.80，段落级 Pearson 仅 33.80。使用 GPT-NeoX、OPT-30B 等其他代理模型时，性能接近随机基线。原因是不同 LLM 的生成模式不同，即使常见 token 在代理模型中的概率也可能很低，当响应与代理 LLM 的生成风格不一致时，代理概率并不可靠。

## 3 三、本文方案及其优点

### 3.1 SelfCheckGPT 总体框架与采样思路

SelfCheckGPT 的核心直觉是：**如果 LLM 掌握了某个概念，那么随机采样得到的多个响应应当是相似的，并且包含一致的事实；而对于幻觉事实，随机采样的响应往往会发散甚至相互矛盾**。

具体地，设 R 为 LLM 对用户查询的主响应，再从同一查询随机采样 N 个响应样本 \{\{S_1,S_2,\dots,S_n,\dots,S_N\}\}。SelfCheckGPT 通过测量 R 的第 i 个句子与这些样本之间的一致性，预测该句子的幻觉分数 S(i)，其中 S(i)∈[0.0,1.0]，S(i)→0.0 表示事实性句子，S(i)→1.0 表示幻觉句子。

本文考虑五种一致性度量变体：**BERTScore、Question Answering、n-gram、NLI、LLM Prompting**。由于 SelfCheckGPT 只依赖采样响应，它可以应用于黑盒模型，且无需外部数据库。实验设置中，主响应使用温度 0.0 和标准 beam search 生成；随机样本使用温度 1.0 生成，样本数 N=20。

### 3.2 变体一：SelfCheckGPT with BERTScore

设 B(·,·) 表示两个句子之间的 BERTScore。该方法计算第 i 个句子与每个采样样本中最相似句子的平均 BERTScore：

$$
S_{\text{BERT}}(i) = 1 - \frac{1}{N}\sum_{n=1}^{N}\max_{k}\left(B(r_i, s_{n,k})\right)
$$

其中 r_i 是主响应 R 中的第 i 个句子，s_{n,k} 是第 n 个采样样本 S_n 的第 k 个句子。

**直觉**：如果某句子的信息出现在多个采样样本中，可以假设它是事实性的；反之，如果某陈述没有出现在任何其他样本中，则很可能是幻觉。本文使用 RoBERTa-Large 作为 BERTScore 的骨干模型。

**结果**：该变体在句子级 AUC-PR 上，NonFact 为 81.96，NonFact\* 为 45.96，Fact 为 44.23；段落级 Pearson 相关为 58.18，Spearman 为 55.90。优于灰盒概率基线。

**优点**：实现简单，无需额外训练，计算量相对较小。
**不足**：BERTScore 基于语义相似度，可能无法捕捉事实矛盾关系；对于主题相关但事实错误的句子区分能力有限。

### 3.3 变体二：SelfCheckGPT with Question Answering（MQAG）

该变体使用多选自动问答生成（MQAG）框架来衡量一致性。MQAG 通过在主响应上生成多选问题，然后让独立问答系统在其他采样响应条件下回答问题。如果问题所询问的信息是一致的，则问答系统应预测相似的答案。

MQAG 包括两个阶段：问题生成 G 与问题回答 A。对于主响应中的句子 r_i，生成问题 q 和选项 o：

$$
q, o \sim P_G(q,o\mid r_i,R)
$$

回答阶段分别在主响应 R 和采样响应 S_n 条件下选择答案：

$$
a_R = \arg\max_k[P_A(o_k\mid q,R,o)]
$$

$$
a_{S_n} = \arg\max_k[P_A(o_k\mid q,S_n,o)]
$$

比较 a_R 是否等于 a_{S_n}，统计匹配数 N_m 和不匹配数 N_n。简单的矛盾分数为：

$$
S_{\text{QA}}(i,q)=\frac{N_n}{N_m+N_n}
$$

为了考虑生成问题的可回答性，进一步应用贝叶斯定理和软计数，得到：

$$
S_{\text{QA}}(i,q)=\frac{\gamma_2^{N'_n}}{\gamma_1^{N'_m}+\gamma_2^{N'_n}}
$$

其中有效匹配数 N'_m 与有效不匹配数 N'_n 通过可回答性分数 α 进行软计数：

$$
N'_m = \sum_{\substack{n \text{ s.t. } a_n\in L_m}} \alpha_n; \quad N'_n = \sum_{\substack{n \text{ s.t. } a_n\in L_n}} \alpha_n
$$

α_n = P_U(answerable|q,S_n)。γ_1 = β_2/(1-β_1)，γ_2 = β_1/(1-β_2)，本文设置 β_1=β_2=0.8。最终句子级分数为跨问题的期望：

$$
S_{\text{QA}}(i) = \mathbb{E}_q[S_{\text{QA}}(i,q)]
$$

此外，本文采用两阶段问题生成提升干扰项质量：

$$
q,a \sim P_{G1}(q,a\mid r_i); \quad o_{\backslash a} \sim P_{G2}(o_{\backslash a}\mid q,a,R)
$$

其中 o = {a, o_{\backslash a}} = \{o_1,...,o_4\}。具体系统中，问题生成器 G1、G2 分别为在 SQuAD 和 RACE 上微调的 T5-Large；回答系统 A 为在 RACE 上微调的 Longformer；可回答性系统 U 为在 SQuAD2.0 上微调的 Longformer。

**结果**：该变体句子级 AUC-PR：NonFact 为 84.26，NonFact\* 为 40.06，Fact 为 48.14；段落级 Pearson 为 61.07，Spearman 为 59.29。消融实验显示：简单计数为 83.97/40.07/47.78；加入贝叶斯修正后为 83.04/38.58/47.41；再加入软计数 α 后为 84.26/40.06/48.14，段落相关度从 57.39/55.15 提升到 61.07/59.29。

**优点**：多选问答能更明确地判断事实一致性；可回答性加权能过滤低质量问题；能利用 QA 模型的推理能力。
**不足**：流程较复杂，依赖多个微调系统；整体计算成本较高。

> **追问**：MQAG是什么
>
> **解答**：MQAG（Multiple-choice question answering and generation）是一种用于评估信息一致性的框架，在 SelfCheckGPT 中作为 QA 变体使用。它分为两个阶段：先在主响应 R 的句子 r_i 上自动生成多选问题 q 和选项 o；再用独立问答系统分别以 R 和其他采样样本 S_n 为上下文作答。若信息一致，答案应相同；若不一致，则说明该句可能包含幻觉。SelfCheckGPT 用不匹配比例作为幻觉分数，并通过可回答性分数 α 进行软计数和贝叶斯修正，以提升稳健性。该变体在句子级 NonFact 任务上 AUC-PR 达 84.26，优于 BERTScore 变体。

> > **追问**：问题和选项具体是如何生成的
> >
> > **解答**：具体生成采用两阶段式。第一阶段的生成器 \(G_1\) 基于待评估句子 \(r_i\) 生成问题 \(q\) 及正确答案 \(a\)：
> > 
> > \[
> > q,a \sim P_{G1}(q,a\mid r_i)
> > \]
> > 
> > 第二阶段的生成器 \(G_2\) 利用问题、正确答案和主响应 \(R\) 生成干扰选项 \(o_{\backslash a}\)：
> > 
> > \[
> > o_{\backslash a} \sim P_{G2}(o_{\backslash a}\mid q,a,R)
> > \]
> > 
> > 最终选项集为 \(o=\{a,o_{\backslash a}\}=\{o_1,\dots,o_4\}\)，共四个选项。在论文实现中，\(G_1\) 和 \(G_2\) 分别是 T5-Large 在 SQuAD 和 RACE 数据上微调的模型。问答系统 \(A\) 为在 RACE 上微调的 Longformer，可回答性系统 \(U\) 为在 SQuAD2.0 上微调的 Longformer。该两阶段设计能生成更高质量的干扰项。

> > > **追问**：公式里的~符号是什么意思
> > >
> > > **解答**：在论文中，波浪号 `~` 有两种常见用法：
> > > 
> > > 1. **表示“服从分布”或“从分布采样”**  
> > >    例如 \(q, o \sim P_G(q,o \mid r_i, R)\) 读作“问题 \(q\) 和选项 \(o\) 从分布 \(P_G\) 中采样得到”。它说明变量是某个概率分布的随机样本，而非确定性结果。
> > > 
> > > 2. **表示“估计值/近似值”**  
> > >    例如 n-gram 变体中的 \(\tilde p_{ij}\)。这里的波浪号写在变量上方，表示由 n-gram 语言模型估计出的近似概率，以区别于原始 LLM 的真实输出概率 \(p_{ij}\)。类似地，\(H_{ij}\) 计算中的 \(\tilde w\) 只是遍历词汇表的候选词变量。
> > > 
> > > 简言之：**位置在变量上方时表示“近似/估计”，位置在两个表达式之间时表示“采样自某分布”**。

> > > **追问**：根据句子r_i，生成的问题q是什么形式的？
> > >
> > > **解答**：论文未给出具体的模板示例，但从 MQAG 框架与实现可推断：问题 \(q\) 是由 \(G_1\) 针对句子 \(r_i\) 的关键事实信息自动生成的自然语言疑问句，形式类似于机器阅读理解中的多选题。例如，若 \(r_i\) 为 “Giuseppe Mariani was born in Milan, Italy.”，\(G_1\) 可能生成 “Where was Giuseppe Mariani born?”，并同时产出正确答案 “Milan, Italy”。由于 \(G_1\) 是在 SQuAD 上微调的 T5-Large，其生成的问题形式与该数据集中常见的基于文本的事实型疑问句一致，通常询问实体、时间、地点、属性等。

### 3.4 变体三：SelfCheckGPT with n-gram

给定采样样本 \{S_1,...,S_N\}，可以用这些样本训练一个简单的 n-gram 语言模型来近似原 LLM。当 N 足够大时，该语言模型将收敛于生成响应的 LLM。实践中，由于时间/成本限制，N 有限。因此，本文使用样本 \{S_1,...,S_N\} 以及主响应 R（相当于给 R 中每个 token 的计数加 1 的平滑方法）训练 n-gram 模型。

计算句子中 token 的平均负对数概率：

$$
S_{\text{Avg n-gram}}(i) = -\frac{1}{J}\sum_{j}\log \tilde p_{ij}
$$

以及最大负对数概率：

$$
S_{\text{Max n-gram}}(i) = \max_{j}(-\log \tilde p_{ij})
$$

其中 \tilde p_{ij} 是由 n-gram 模型计算的第 i 个句子第 j 个 token 的概率。

**直觉**：如果一个 token 在所有采样样本中出现次数很少（甚至只出现一次），则该 token 很可能是非事实性的。实验发现“最大”版本比“平均”版本更有效。

**结果**：unigram（max）在句子级 AUC-PR 上，NonFact 为 85.63，NonFact\* 为 41.04，Fact 为 58.47；段落级 Pearson 为 64.71，Spearman 为 64.91，优于多数灰盒方法。N-gram 阶数消融（表 7）显示：对 max 方法，随着 n 从 1 增大到 5，NonFact AUC-PR 从 85.63 降至 84.12，性能逐步下降；而平均方法则从 81.52（1-gram）升至 83.80（4-gram），但仍低于 unigram max。因此，简单找到最不可能出现的 token/n-gram 是更有效的策略。

**优点**：计算开销极低，实现简单，无需外部模型。
**不足**：基于 token 频率，缺乏语义理解；未给出有界分数；需要较多样本才能达到稳定性能。

### 3.5 变体四：SelfCheckGPT with NLI

自然语言推理（NLI）判断假设是否由前提蕴含，通常分为 entailment/neutral/contradiction 三类。受基于 NLI 的摘要忠实性评估启发，本文使用 NLI 的 contradiction 分数作为幻觉分数。

使用 DeBERTa-v3-large 在 MNLI 上微调作为 NLI 模型。将采样段落 S_n 作为前提，待评估句子 r_i 作为假设，计算矛盾概率：

$$
P(\text{contradict}\mid r_i,S_n)=\frac{\exp(z_c)}{\exp(z_e)+\exp(z_c)}
$$

其中 z_e、z_c 分别为 entailment 和 contradiction 类的 logit。该归一化忽略了 neutral 类，确保概率有界。对 N 个样本取平均：

$$
S_{\text{NLI}}(i) = \frac{1}{N}\sum_{n=1}^{N}P(\text{contradict}\mid r_i,S_n)
$$

**直觉**：如果某句子被多个采样响应判断为矛盾，则该句子很可能是幻觉。

**结果**：该变体句子级 AUC-PR：NonFact 为 92.50，NonFact\* 为 45.17，Fact 为 66.08；段落级 Pearson 为 74.14，Spearman 为 73.78。性能非常接近 Prompt 方法。

**优点**：性能强，且计算成本比 Prompt 方法低，是性能与计算之间的良好折中方案。
**不足**：依赖外部 NLI 模型的领域适应性；NLI 训练数据与事实核查的分布可能存在差异。

### 3.6 变体五：SelfCheckGPT with Prompt

LLM 已被证明能在零样本设定下有效评估信息一致性。本文直接查询 LLM，判断第 i 个句子是否由样本 S_n（作为上下文）支持。使用以下提示模板：

```text
Context: {}
Sentence: {}
Is the sentence supported by the context above?
Answer Yes or No:
```

初步研究显示，GPT-3（text-davinci-003）在 98% 的情况下会输出 Yes 或 No，其余输出可归为 N/A。将输出映射为分数：Yes→0.0，No→1.0，N/A→0.5。最终分数为：

$$
S_{\text{Prompt}}(i) = \frac{1}{N}\sum_{n=1}^{N}x_n^i
$$

其中 x_n^i 是第 i 句与第 n 个采样响应比较得到的分数。

**结果**：该变体在所有方法中表现最好，句子级 AUC-PR：NonFact 为 93.42，NonFact\* 为 53.19，Fact 为 67.09；段落级 Pearson 为 78.32，Spearman 为 78.30，明显优于灰盒概率/熵方法和其他黑盒方法。

**优点**：零样本、无需训练，利用 LLM 的推理能力直接做一致性判断，效果最好。
**不足**：计算成本高。实验估计，对所有 1908 个句子×20 个样本进行 Yes/No 判断，GPT-3 费用约 200 美元，ChatGPT 约 20 美元。此外，较弱的模型（如 text-curie-001 或 LLaMA）无法有效完成该 prompting 任务。

### 3.7 总体性能对比

下表汇总主要方法在句子级（AUC-PR）和段落级（相关度）上的表现：

| 方法 | NonFact | NonFact\* | Factual | Pearson | Spearman |
|---|---|---|---|---|---|
| Random | 72.96 | 29.72 | 27.04 | - | - |
| GPT-3 Avg(-log p)（灰盒） | 83.21 | 38.89 | 53.97 | 57.04 | 53.93 |
| GPT-3 Max(-log p)（灰盒） | 87.51 | 35.88 | 50.46 | 57.83 | 55.69 |
| LLaMA-30B Avg(H)（代理） | 80.80 | 39.01 | 42.97 | 33.80 | 39.49 |

段落级分数由句子级分数平均得到：

$$
S_{\text{passage}} = \frac{1}{|R|}\sum_{i}S(i)
$$

其中 |R| 为段落中的句子数。主要观察：1）GPT-3 自身概率与事实性高度相关，是强基线；2）代理 LLM 表现明显更差；3）SelfCheckGPT 各变体普遍优于灰盒方法，其中 Prompt 和 NLI 尤为突出。

## 4 四、前景与发展方向

### 4.1 扩展到更广泛的概念类型

当前研究中的 238 段 GPT-3 生成文本主要来自 WikiBio 数据集中关于人物的段落。为了更全面地研究 LLM 幻觉的性质，未来可以将评估扩展到更广泛的概念类型，例如地点、物体、事件等，验证 SelfCheckGPT 在不同领域上的鲁棒性和泛化能力。

### 4.2 细粒度事实性评估：原子事实分解

当前标注和分析基于句子级标签，但一个句子可能同时包含事实性和非事实性信息。未来可以借鉴 FActScore（Min 等，2023）的思想，将句子分解为原子事实，在更细粒度上评估事实性。这有助于更精确地定位幻觉片段，并提升检测分辨率。

### 4.3 降低 SelfCheckGPT-Prompt 的计算成本

SelfCheckGPT-Prompt 虽然效果最好，但计算成本很高，因为需要对每个句子、每个采样样本调用一次 LLM。未来工作可以研究更高效的 prompting 策略，例如批量判断、更小但足够强的评估模型、自适应采样数量等，在保持性能的同时降低 API 调用成本。

### 4.4 结合外部知识源与检索增强

消融实验（表 3）显示，当外部知识源可用时，SelfCheckGPT 中的 NLI 和 Prompt 方法能显著受益：例如 WikiBio+Prompt 的 NonFact AUC-PR 从 93.42 提升到 93.59，Fact 从 67.09 提升到 73.11，段落级 Spearman 从 78.30 提升到 86.11。因此，未来可以在零资源 SelfCheckGPT 基础上，必要时引入轻量级检索增强，形成混合式幻觉检测方案。但需注意外部数据库无法覆盖所有 LLM 使用场景。

### 4.5 改进代理 LLM 与条件语言模型评分

代理 LLM 方法当前表现不佳，但研究表明使用更丰富的熵信息可以改善性能。未来可以考虑引入加权条件语言模型分数，如 BARTScore（Yuan 等，2021），或选择与目标 LLM 生成风格更相似的代理模型，以提升黑盒条件下的概率近似质量。

### 4.6 建立标准化的 LLM 幻觉检测基准

目前缺乏标准的 LLM 幻觉检测数据集。本文发布了一个带句子级事实性标签的 GPT-3 幻觉检测数据集，作为首个公开基准。未来需要更大规模、更多领域、更多模型的标准评测集，以促进幻觉检测方法的系统比较与进步。
