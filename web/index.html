笔记风格管理

    
风格 = 名字 + 说明 + 提示词模板（{raw_text} 为资料全文占位符）。内置风格可改可恢复默认，自定义风格可删除、可改 id（会同时改文件名）；文件在 .paperhelper/styles/。

    
下面只填「内容与结构」要求即可：格式要求（# 标题、## 分节、$公式$、Markdown 表格等）由程序自动附加，不用也不应写在这里。

使用帮助

    
    
      
  • 导入：在「笔记」页点「＋ 导入资料」，或直接把文件拖进窗口（PDF / TXT / MD / HTML）。
    • 
      
  • 论文 / 讲义模式：论文走「论文 → 生成笔记」；自己的笔记或课程讲义走「笔记 / 讲义 → 导入」，可「原样导入（不调模型、0 token）」或选一种风格生成。
    • 
      
  • 自定义风格：导入时选风格，还可填一句「本次额外要求」（如“只翻译”“只留公式和结论”）；「另存为风格」把它存成新风格；「管理…」里可新建 / 编辑 / 复制 / 删除 / 恢复默认。文件在 .paperhelper/styles/（清单 styles.toml，提示词可直接编辑）。
    • 
      
  • HTML 讲义：上传 HTML 会自动转成 Markdown（公式按 KaTeX 隐藏层还原，脚本/事件属性会被剔除；MathJax 的 \newcommand 宏定义会自动注册，公式里的自定义宏也能渲染）。
    • 
      
  • 编辑笔记：悬停标题/段落 → 点「✎ 编辑」。编辑**章节**时会带出该节标题与全部内容；可手动改、或让 AI 重写 / 补充，也可插入内容、删除整块。编辑**主标题**时多一个「按风格重写全文」：选一种笔记风格（可加额外要求）让 AI 重写整篇（会重建块 id、清空批注，可用「撤销」恢复）。
    • 
      
  • 选中提问：在笔记里选中一段文字 → 点浮出的「提问」→ 小窗口内输入问题（可切 ask / check）。选中公式会把它在 KaTeX 里的原始 LaTeX 交给模型；多行输入用 Shift+回车换行、回车发送。
    • 
      
  • 章节提问：右键笔记里的标题（h1=全文，h2/h3=小节）→「对本章节提问」。
    • 
      
  • 回答里追问：在批注小窗口的回答里选中文字 → 浮出「提问」→ 新问答挂在该回答下，选中文字持久高亮，点高亮可回看。选区不会被清掉，输入框上方还有「引用」附件条显示这次问的是哪一段；「记概念」勾选框可决定是否把知识点写进「已学概念」。
    • 
      
  • 打开批注：点击黄色高亮文字（或标题）重新打开小窗口。
    • 
      
  • 批注操作：小窗口内节点左键跳转、右键删除/总结；右键高亮文字可删除整条批注。小窗口可拖动标题栏移动，四条边 + 四个角都能拖拽缩放（尺寸记忆、无上限；双击把手恢复默认），输入栏在底部、可拖上缘调整高度，「思考过程」区也可拖下缘调高度。
    • 
      
  • 进度与思考：等待模型时显示上下文规模与计时；推理模型的思考过程会流式显示在「思考过程」折叠区。
    • 
      
  • 并发与等待：导入 / 提问等 LLM 任务同时只能有一个；生成期间仍可浏览、切换会话（切换会放弃未写入的回答），导入遇到会话切换会自动另存为新会话；再发起第二个 LLM 操作会提示等待。
    • 
      
  • 导入反馈在笔记区：导入/生成笔记时不再刷控制台——「笔记」页会实时显示阶段（解析 PDF / 文本已就绪 / 生成中）、思考过程与正在生成的笔记文本；控制台只在出错时自动打开。
    • 
      
  • 导出：点「导出」下载 Markdown / 思维导图 / HTML。
    • 
      
  • 撤销：删除后点「撤销」恢复。
    • 
      
  • 配置：点「配置」修改 API 端点/密钥/模型/价格/预算。
    • 
      
  • 列表多选：侧栏的会话 / 论文 / 概念列表，Ctrl(⌘) 点选、Shift 连选，右键可批量置顶 / 删除；Esc 取消选择。
