使用帮助

    
    
      
  • 导入：在还没有笔记的「笔记」页点「＋ 导入论文」，或直接把 PDF/TXT 拖进窗口。
    • 
      
  • 选中提问：在笔记里选中一段文字 → 点浮出的「提问」→ 小窗口内输入问题（可切 ask / check）。
    • 
      
  • 章节提问：右键笔记里的标题（h1=全文，h2/h3=小节）→「对本章节提问」。
    • 
      
  • 打开批注：点击黄色高亮文字（或标题）重新打开小窗口。
    • 
      
  • 批注操作：小窗口内节点左键跳转、右键删除/总结；右键高亮文字可删除整条批注。
    • 
      
  • 导出：点「导出」下载 Markdown / 思维导图 / HTML。
    • 
      
  • 撤销：删除后点「撤销」恢复。
    • 
      
  • 配置：点「配置」修改 API 端点/密钥/模型/价格/预算。
